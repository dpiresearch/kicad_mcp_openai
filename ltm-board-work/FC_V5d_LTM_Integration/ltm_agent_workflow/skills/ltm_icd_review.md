# Skill: LTM ICD Review

Read the current LTM ICD and update `requirements_memory.json` before board edits.

Checklist:

- Capture mechanical constraints, stack placement, connector constraints, and unavailable pass-through assumptions.
- Capture power limits, inhibit conditions, and umbilical behavior.
- Capture CAN addressing, host source/destination rules, and optional I2C directionality.
- Capture RF antenna obligations without copying proprietary ICD text.
- Mark every ambiguous item as needing exact LIHU Gerber/KiCad confirmation.
